# ScanSplitter 0.7.0

This release makes photo archiving safer: projects preserve original source
files, review protects your edits, and exports use retained image data rather
than display previews. It also brings consistent detection controls to Quick
and Projects and improves review on smaller screens.

## Original preservation and export quality

- New project imports retain immutable original files with SHA-256 checksums,
  alongside separate lossless processing images and display previews.
- PDF crops and exports render from the retained PDF at 300 DPI, while review
  uses 150-DPI coordinates.
- Quick mode retains lossless crop assets for downloads; rotating a preview
  no longer changes or degrades the downloadable pixels.
- Individual downloads, ZIP downloads, and local exports share encoding and
  metadata handling. Project previews and exports share cleanup, restoration,
  orientation, and manual rotation settings. GPS metadata remains opt-in.

## Safer review and background processing

- Stale detection results cannot overwrite later edits, and stale project saves
  are rejected rather than silently replacing newer work.
- Interrupted or cancelled detection returns to a retryable state. Restarting
  the app does not automatically repeat paid Cloud AI requests.
- Deleting a project cancels its jobs and prevents late results from recreating it.
- Review saves are serialized, save state is visible, and failed saves stop
  dependent navigation, preview, and export actions.
- Unsaved review drafts are protected when switching modes or leaving the page.
  Polling retries transient failures and ignores out-of-order responses.
- Quick mode keeps separate drafts for visited PDF pages. Crop All includes
  every edited page with boxes, and closing a file releases its server session.

## Clearer controls and more accessible editing

- Quick and Projects now share Photos/Album pages, Local/Cloud AI, layout,
  auto-detect, auto-rotate, area limits, and cleanup controls. Detector versions
  are grouped under Advanced, and both workflows disclose Cloud AI transmission.
- Improved narrow-screen layouts, canvas resizing, zoom, scroll-to-pan, and
  keyboard-accessible numeric geometry controls.
- Added an explicit Save edits action and selected-photo filename/caption fields.
- Grouped project export options and delivery access in one dialog, improved
  dialog focus handling, and prevented review shortcuts from interfering with
  form controls or open dialogs.
- Improved protection for unsaved metadata and made front/back pairing easier
  to inspect, unlink, and reassign.

## Import and delivery reliability

- Project import batches commit only after every file validates; failures remove
  staged data instead of leaving partially imported batches.
- Added bounded upload, PDF, image, job-queue, and preview-cache limits. Export
  jobs build temporary ZIP files on disk and stream downloads.
- Delivery records confirmed files and their content hashes so retries skip
  unchanged files already delivered to the same connection.
- Folder retries restore missing files and reject conflicting content unless
  overwrite is selected. Nextcloud uses conditional uploads by default.
- Delivery checks cancellation between files, preserves credential values
  exactly, and prevents saved secrets from being reused with a different server
  or Nextcloud username.

## Upgrade notes

- **New detections require manual review.** Geometry checks still flag potential
  problems, but no longer automatically approve scans. Manual approval is labelled
  Reviewed; legacy automatic statuses are labelled Detected and remain exportable.
- **Existing projects remain readable.** Projects created before original-file
  retention may contain only derivatives. The UI identifies these and recommends
  re-importing original files for archival output. Re-import creates new scans;
  it does not automatically transfer existing boxes or metadata.
- Retained originals preserve their source bit depth, profiles, and metadata.
  Processed outputs use the current 8-bit RGB pipeline, so PNG/TIFF masters do
  not replace the retained originals.
- Crop All still requires visiting and detecting previously unvisited PDF pages.
- Cancellation does not undo files already delivered. If a remote server accepts
  a file but its acknowledgment is lost, retries remain subject to that server's
  duplicate/conflict behavior.
- Python 3.13 or newer is still required. Runtime and frontend dependencies have
  been refreshed, including FastAPI, NumPy, ONNX Runtime, React, Vite, and Vitest.

## Validation

Expanded backend and frontend regressions cover original preservation,
transactional imports, cancellation/restart behavior, stale saves, export parity,
delivery retries, per-page drafts, and failed-save navigation. The release is
validated with 176 backend tests, 31 frontend tests, both linters, a production
frontend build, and package-content checks.

These checks are not certification for large collections, screen readers, or
specific Immich/Nextcloud production deployments.
