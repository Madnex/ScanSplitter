# ScanSplitter 0.6.0

This release adds more capable photo and album detection, clearer splitter
controls, and more precise export cleanup.

## Detection

- Added **ScanSplitter v5**, combining conservative local anchors with texture,
  frame, and segmentation evidence to recover pale, edge-adjacent, and mounted
  photos while keeping crop boundaries tight.
- Added **Album Splitter** for preserving complete physical album pages, with
  automatic, single-page, and split-spread layouts.
- Added an experimental **Cloud AI** detector for Quick mode and persistent
  Projects. It asks a configurable OpenRouter vision model for the inner image
  corners and clearly discloses that the complete scan leaves the machine.
- OpenRouter detection now retries transient network/provider failures, rejects
  malformed and duplicate geometry, and caches successful coordinate responses
  locally to avoid repeat charges for unchanged inputs.
- Project uploads, Detect Pending, Re-detect All, and single-scan re-detection
  now honor the saved Cloud AI mode and preserve actionable provider errors on
  failed background jobs.
- Decommissioned ScanSplitter v1 and v2. ScanSplitter v3 and v4 remain
  available for comparison and existing workflows.

## Cropping and workflow

- Tight edge cleanup is now the default and more reliably snaps to inner photo
  edges while excluding scanner background, paper borders, and residual halos.
- Project review includes per-photo details and page export improvements, plus a
  fix for loading very large project scans.
- Quick-mode splitter controls now separate photo versus album-page output and
  local versus Cloud AI detection in a compact layout.

## Documentation and validation

- Added fixed visual benchmarks for current local, album, and OpenRouter
  detectors, including committed results for `google/gemini-3.7-flash`.
- Documented OpenRouter privacy, caching, retries, configuration, and binding
  Quick/Project feature parity expectations.
- Updated dependencies and expanded backend/frontend regression coverage for the
  new detectors and settings.
